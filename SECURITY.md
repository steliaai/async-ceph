# Security Policy

To report a vulnerability, please use the [GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately) (GHSA).

- Please do not open a public GitHub issue to report a vulnerability.

- We commit to acknowledging security reports within 2 working days.

- Please provide as much information as possible as part of the report, namely:
    - Affected versions
    - Minimal reproducer
    - Fix, if any
    - Planned disclosure date, if any
    - Additional researchers to credit, if any
